# بوت واتساب لبياعين مكينات القهوة ☕

كيعرض الكتالوج، كيجاوب على التوصيل والضمان والأوقات، كياخد الطلب (المنتج + الاسم + المدينة) وكيصيفطو للمالك على واتساب. كيهضر بالدارجة والفرنسية أوتوماتيكيا حسب لغة الزبون.

## 1) التعديل (دقيقتين)
عدّل `catalog.json`: اسم المحل، المدينة، الأوقات، المنتجات والأثمنة، التوصيل والضمان.
الأثمنة اللي فيه دابا **أمثلة** فقط.

## 2) التجربة بلا واتساب
    node test.js

## 3) الربط بواتساب بزنس
1. فـ developers.facebook.com صاوب Business App وزيد منتج **WhatsApp**.
2. نسخ `PHONE_NUMBER_ID` وصاوب **توكن دائم** (System User).
3. `cp .env.example .env` وعمّرو.
4. شغل البوت: `node --env-file=.env server.js`
5. حطو على نت بـ HTTPS (Render / Railway / VPS، ولا `ngrok` للتجربة).
6. فـ Meta > WhatsApp > Configuration: Callback URL = `https://دومينك/webhook` و Verify token = `VERIFY_TOKEN`، واشترك فـ **messages**.

## ملاحظات
- رقم واتساب بزنس خاصو يكون مسجل فـ Cloud API (ماشي مستعمل فتطبيق واتساب العادي).
- الزبون اللي بدا المحادثة ديما كيقدر تجاوبو 24 ساعة؛ ومن بعد خاص templates ديال Meta.
- الجلسات كتتخزن فالذاكرة: إيلا عاود السيرفر كتبدا من الأول.

## 4) الذكاء الاصطناعي (Claude) — اختياري
- كيجاوب على الأسئلة الحرة اللي ما فهمهاش البوت بالقواعد (مثلا "واش كتصلحو المكينات؟")، بالدارجة أو الفرنسية، وكيعتمد غير على `catalog.json`.
- الطلبات والقائمة كيبقاو بالقواعد (سريعين وبلا تكلفة).
- إيلا الزبون بغا إنسان، البوت كيصيفط ليك إشعار.
- التفعيل: صاوب مفتاح API من **console.anthropic.com** وحطو فـ `.env` فـ `ANTHROPIC_API_KEY`. بلا مفتاح، البوت كيخدم بالقواعد فقط.
- كل رد كيتحاسب (استعمال API مدفوع): استعمل الموديل الصغير `claude-haiku-5-5` (الافتراضي)، وشوف الأثمنة الحالية فالموقع.
- تجربة المنطق بلا مفتاح: `node test-ai.js`

## ⚠️ خاص تأكد منها مع صاحب المحل
- **التوصيل والضمان**: الرسائل الحالية عامة ("كلم الفريق"). عوضها بالمعلومات الحقيقية فـ `catalog.json` (`delivery` و`warranty`).
- **Électrovanne** (250 درهم) و**Panier filtre** (20 درهم): تأكد من الاسم والثمن والمقاس (الصمام "romlesage" فهمناه تعبئة/remplissage).
- **Voyant lumineux rouge**: ظهر فالموقع ولكن ما عندوش ثمن، ما تزادش فالكتالوج.
